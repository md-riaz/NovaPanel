# Confined real nginx acceptance lab

Run `python3 tools/real_nginx_lab.py` from a clean committed worktree with Go, Docker and TMPDIR pointing to task scratch. The script builds a static test binary, archives the exact commit, copies both into a new task-owned container, verifies its security settings, executes the opt-in tests three times, preserves commands and nginx logs in scratch, and removes that container. No source bind mount, host network, published port, privilege or added capability is used. Tests refuse root, non-container execution, effective capabilities and missing no-new-privileges.

The tested seams are Render/Applier/StateProbe, TLS Stage/Publish/Restore, and the site.update job executor with real SQLite. Runner injection only translates production nginx validation/systemctl reload to container-local `nginx -p <scratch> -c <scratch>/nginx.conf -t/-s reload`. The production rendered bytes and LKG are unchanged. A test-only copy changes listeners 80/443 to 8080/8443 and the maintenance root to scratch. All nginx files and processes stay inside the container.

Coverage includes the three render states, both HTTP2 directive shapes on nginx 1.29.5, populated and missing challenge paths without redirects, maintenance 503 page, rejected force HTTPS without TLS, real syntax-validation failure with no reload, real HTTP 503 probe failure with config rollback, generated manual self-signed TLS acceptance with exact-leaf rejection after replacement, complete versioned-pair publication and pointer restoration, and primary rekey success plus reverse-rekey probe failure restoring service, target pointer and SQLite primary.

This is not the full Phase 3 gate. Challenges run on high internal port 8080, not literal 80. No CA is contacted and no Pebble issuance is claimed. TLS publication is exercised directly, not through ssl.upload admission/sealing. The primary-rekey job uses an injected trusted root caller while the process itself is nonroot; it is not Unix peer authentication coverage. The failed probe uses a real maintenance 503 with intentionally nonmaintenance expectations. A missing docroot alone returns 404 and is accepted by the documented health policy. Reload uses real SIGHUP, not systemd. Per-site user creation/ownership, boot, crash/power-loss and browser acceptance remain separate.
